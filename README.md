# 🍶 酒蔵棚 — SAKAGURA-DANA

飲んだお酒の感想と、バイト先で覚えたお酒の知識を書きためるパーソナルWebアプリ。
PWA対応でスマホのホーム画面にインストールでき、レスポンシブデザインでPC・タブレット・スマホすべてに対応しています。

## ✨ 機能

### 🥃 飲んだお酒日記
- お酒の名前・種類・飲んだ日・場所を記録
- ★5段階評価
- 味の特徴をタグで選択（甘口・辛口・フルーティなど）
- 自由記述メモ

### 📚 お酒知識メモ
- バイト先のお酒情報をまとめて管理
- 産地・製造元・アルコール度数
- お客さんへの説明ポイントをメモ
- タグで整理

### 🏮 棚UIデザイン
- お酒の種類ごとに色が変わるCSSボトルデザイン
- ラベルに登録名が表示される
- ホバーでボトルが持ち上がる演出（タッチ端末ではタップ演出）

### 📱 PWA / レスポンシブ対応
- ホーム画面にアプリとしてインストール可能
- オフラインでも起動できるService Workerキャッシュ
- スマホではモーダルがボトムシート表示
- 画面幅に合わせて棚のボトル数・レイアウトを自動調整
- セーフエリア（ノッチ・ホームバー）対応

## 🚀 使い方

Service Worker を利用するため、ローカルサーバー経由で開いてください。

```bash
# 例: Python
python -m http.server 8000

# 例: Node.js
npx serve .
```

ブラウザで `http://localhost:8000` を開きます。
`index.html` を直接開く（file://）とPWA機能は動作しません。

データはブラウザの localStorage に自動保存されます。

### インストール方法
- **Android / Chrome**: メニュー →「アプリをインストール」または「ホーム画面に追加」
- **iPhone / Safari**: 共有ボタン →「ホーム画面に追加」
- **PC / Chrome・Edge**: アドレスバー右側のインストールアイコン
