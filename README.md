# 🍶 SAKĒ NOTE — お酒ノート

飲んだお酒の感想と、バイト先で覚えたお酒の知識を書きためるパーソナルWebアプリ。

## ✨ 機能

### 🥃 飲んだお酒日記
- お酒の名前・種類・飲んだ日・場所を記録
- ★5段階評価
- 味の特徴をタグで選択（甘口・辛口・フルーティなど）
- 自由記述メモ

### 📚 お酒知識メモ
- バイト先のお酒情報をまとめて管理
- 産地・製造元・アルコール度数
- お客さんへの説明ポイントをメモ
- タグで整理

### 🏮 棚UIデザイン
- お酒の種類ごとに色が変わるCSSボトルデザイン
- ラベルに登録名が表示される
- ホバーでボトルが持ち上がる演出

## 🚀 使い方

`index.html` をブラウザで開くだけで動きます。インストール不要。

データはブラウザの localStorage に自動保存されます。
